SECURITY FRONT — LEAD STORY
ShinyHunters Extortionists Bypass WAF to Attack Oracle PeopleSoft Worldwide
Campaign: Oracle PeopleSoft Exploitation  •  Global  •  Attack Type: WAF Bypass + RCE  •  Exploiting CVE-2026-35273 🔴 Confirmed HIGH Confidence
WHAT HAPPENED: The ShinyHunters group is leveraging a sophisticated URL-encoding technique to circumvent web application firewall (WAF) defenses, actively exploiting CVE-2026-35273 in Oracle PeopleSoft deployments. This flaw enables remote code execution without authentication and is being weaponized in mass campaigns.
IMPACT: Organizations running unpatched PeopleSoft servers are facing widespread exploitation, live web shell deployments, and possible data compromise across multiple sectors.
WHY IT MATTERS: This is not a theoretical threat—exploitation is disrupting business operations globally, raising red flags about WAF limitations and the urgency for prompt patching. The campaign lays bare how quickly attackers exploit even short-lived security gaps.
