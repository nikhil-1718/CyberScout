Citrix NetScaler Zero-Days Under Active Attack—Patches Released, Enterprises on Red Alert
Category: Critical Remote Code Execution · Published: Sep 27, 2026 · Status: CONFIRMED
Product: Citrix NetScaler ADC & Gateway   Attack Type: Remote Code Execution (RCE) Zero-Day
CVEs: CVE-2026-88771, CVE-2026-88772
Status: Exploited in the wild (Patch available now)
WHAT HAPPENED
Two critical zero-day vulnerabilities in Citrix NetScaler ADC and NetScaler Gateway—Improper Input Validation (CVE-2026-88771) and Improper Restriction of Operations within the Bounds of a Memory Buffer (CVE-2026-88772)—have been confirmed as actively exploited in real-world attacks. Citrix has released urgent security updates in response.
IMPACT
These flaws allow remote code execution, potentially granting attackers full control over affected devices, with widespread enterprise impact possible. Devices running in default configurations are at risk.
WHY IT MATTERS
NetScaler devices are widely used for application delivery and remote access—making this a Tier 1 supply chain risk. Rapid mass exploitation could disrupt major services globally if unpatched systems remain online.
